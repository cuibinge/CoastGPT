## 3. LLM 推理测试（主体模型）

### 单张推理

```bash
# Shell 包装
bash scripts/run_infer.sh <image_path> "Describe this coastal scene." output.json

# Python 直接调用
python Inference.py \
    --model-path ./FINAL.pt \
    --image <image_path> \
    --prompt "Detect aquaculture areas in this image." \
    --output result.json

# 指定 georef 元数据
python Inference.py \
    --model-path ./FINAL.pt \
    --image <image_path> \
    --prompt "[DET] 检测海岸线" \
    --georef '{"source_crs":"EPSG:4326","model_transform":[1e-5,0,0,0,-1e-5,0]}' \
    --output result.json
```

### 权重检查

```bash
python Tools/inspect_weights.py <checkpoint.pt>
```

## 5. Stage 2 评估

### 批量评估

```bash
python Tools/run_stage2_batch_eval.py \
    --config Configs/step2_dual.yaml \
    --model-path <checkpoint.pt> \
    --data-path <dataset_root> \
    --output <results_dir>
```
输出：`<results_dir>/eval_metrics.json`（含场景分类、VQA、视觉定位、描述等多任务指标）

### GeoJSON 批量评估

```bash
python Tools/run_geojson_batch_eval.py \
    --config Configs/step3_dual.yaml \
    --model-path <checkpoint.pt> \
    --data-path <dataset_root> \
    --output <results_dir>
```


### PoC-3 海岸线（Edge Detection）

```bash
# 训练
python scripts/poc_stage_edge.py \
    -c configs/poc3_edge_a1_focal_dice.yaml \
    --device npu --epochs 10 \
    --unified-labels outputs/poc3_labels_unified/labels_224 \
    --output outputs/poc3_edge/a1_relabel

# A2 多尺度版本
python scripts/poc_stage_edge.py \
    -c configs/poc3_edge_a2_relabel.yaml \
    --device npu --epochs 20 \
    --unified-labels outputs/poc3_labels_unified/labels_224

# 单张推理 TIF → GeoJSON
python scripts/poc3_edge_infer.py \
    --image <4-band.tif> \
    --geojson <label.geojson> \
    --output output.geojson \
    --threshold 0.25

# 批量推理 + 阈值扫描 + GeoJSON 评估
python scripts/poc3_batch_infer.py \
    --output outputs/poc3_edge/batch_eval \
    --threshold-sweep "0.05:0.90:0.05" \
    --threshold-select-metric buffered_f1_3px \
    --threshold-by-category

# A2 归因诊断（FP distance, oracle ceiling, per-side output）
python scripts/diag_a2_attribution.py \
    --config configs/poc3_edge_a2_soft_multiscale.yaml \
    --checkpoint <checkpoint.pt> \
    --output outputs/poc3_edge/diag

# 构建统一标签
python scripts/poc_stage_edge.py \
    -c configs/poc3_edge_a1_focal_dice.yaml \
    --build-manifest-only
```
